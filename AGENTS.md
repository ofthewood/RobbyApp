# Directives et Règles du Projet mt5_scalpv2

## Règle de Versioning & Git Commits
- **Rappel systématique des commits** : Dès qu'une fonctionnalité est terminée, qu'un bug est corrigé ou qu'un ensemble de modifications est validé, rappelle systématiquement à l'utilisateur de commiter les changements sous Git et de pousser sur GitHub.
- Propose toujours la commande groupée prête à l'emploi (`git add ...; git commit -m "..."; git push origin main`) avec un message de commit clair et synthétique en anglais conventionnel (`feat:`, `fix:`, etc.).
